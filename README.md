# Hybrid Fingerprinting of Neural Networks (Extended)

The source code of the experiments of the following extended paper:

C. Aknesil, E. Dubrova, N. Lindskog, J. Sternby, and H. Englund,
"Hybrid Fingerprinting for Effective Detection of Cloned Neural
Networks," 2025.

The data associated with the experiments will be made available upon request.
